# African Gaming Archive

A visual archive documenting gaming culture across Africa—studios, creators, esports, and the spaces where gaming happens.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Sanity CMS
- React Router

## Features

- Studio profiles with games and interviews
- Country filtering
- CMS-powered content management
- Responsive design

## Setup
```bash
npm install
npm run dev
```

## CMS

Content managed through Sanity Studio at `/studio`
